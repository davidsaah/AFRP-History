Building it

The book is not a document with a build script bolted on. The book is the program's output — every figure, map, chart, citation and correction is generated from source at build time, and the same sources produce byte-identical HTML.

python build.py  →  out/AFRP_The_One_Line_v5.html

Corrections

Corrections are the point. If you can show that something here is wrong, open an issue with the source — author, work, year, page. The book is designed to absorb that: it prints its own retractions, at the same size as the claims they replace.
