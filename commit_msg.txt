Fix push.ps1, and stop committing the push log

The one-click push script had been silently failing since it was written. It set
$ErrorActionPreference = 'Stop', and git writes its CRLF warnings to stderr, which
PowerShell then treats as a terminating error - so the script died during `git add`
and never reached `git commit`. It opened a console, printed a few lines and closed,
which looked exactly like success. Nothing had gone up since 21 August because of it.

  * ErrorActionPreference is now 'Continue', with a comment saying why.
  * The commit message moved to commit_msg.txt, so nothing depends on surviving
    PowerShell here-string quoting.
  * GIT_TERMINAL_PROMPT=0 so a credential prompt fails fast instead of hanging.
  * The script prints both refs and says not to trust the GitHub web page, which
    has served stale data on this repo.

Also: push_log.txt is now gitignored and untracked - it was swept into c433ec8
while it was still being written.
